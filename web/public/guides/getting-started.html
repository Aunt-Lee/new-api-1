NewtonRouter API guide

NewtonRouter is a unified AI model API platform. Use one API address and key to access models from families such as GPT, Claude and Grok. The platform provides model price comparisons, API keys, usage records and subscription plans.

Who is NewtonRouter for?

Individual developers, AI application teams and automation users who want to compare models and connect them through a common interface. OpenAI-compatible clients can use NewtonRouter by configuring the API Base URL, API key and model ID. Each client's supported features still depend on the model and endpoint selected.

Connect an application

  1. Register and sign in. Add balance or choose a plan as needed.
  2. Create an API key in the console.
  3. Set the OpenAI-compatible SDK Base URL to https://newtonrouter.com/v1, supply your key and select an available model ID from model pricing.

If your client appends /v1 automatically, use https://newtonrouter.com instead. Avoid sending requests to a path containing /v1/v1.

Chat Completions request example

Replace YOUR_API_KEY and MODEL_ID with your key and an available model that supports Chat Completions. 

curl https://newtonrouter.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

Pricing and availability

The model pricing page is the source for currently available models and their displayed rates. Input and output token prices can differ, and the selected group affects the rate. Review the model's units and billing rules before making requests.

The plans page lists available subscriptions and token usage estimates. Estimates depend on the selected model and input/output assumptions; they are not a guaranteed token allowance. Models, prices and plans may change.

Frequently asked questions

Is NewtonRouter a model provider's official website?

NewtonRouter is an API platform that routes requests to upstream services. OpenAI/GPT, Anthropic/Claude and xAI/Grok are separate providers and brands. Their names identify model families and do not imply endorsement.

Can I use every provider feature through the same API?

Support varies by model, endpoint and channel. OpenAI-compatible does not mean every provider-specific feature is supported. Check the model's supported endpoints and test the features required by your application.

What does the 24-hour success rate mean?

It is an observed service statistic shown on the pricing page, not a future uptime guarantee or the provider's official status. Where a group is represented by one model, the displayed model name identifies that data source.

Where can I check spending?

Sign in to view your balance, request logs and usage records in the console.

Where can I ask for help?

Contact newtonrouter@gmail.com. Read the user agreement and privacy policy for service terms and data handling.
