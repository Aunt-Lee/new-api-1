NewtonRouter 接入指南

NewtonRouter 是一个 AI 模型统一接口平台，使用一个 API 地址和密钥，即可接入 GPT、Claude、Grok 等系列模型。平台提供模型价格对比、API 密钥、调用记录和订阅套餐。

适合谁使用？

适合需要对比模型并通过统一接口接入的个人开发者、AI 应用团队和自动化用户。兼容 OpenAI API 的客户端可通过配置 Base URL、API Key 和模型 ID 接入；具体功能仍取决于所选模型和接口。

如何接入应用？

  1. 注册并登录，按需充值或选择套餐。
  2. 在控制台创建 API Key。
  3. 将 OpenAI 兼容 SDK 的 Base URL 设置为 https://newtonrouter.com/v1，填入密钥，并从模型定价页面选择可用的模型 ID。

如果客户端会自动添加 /v1，请填入 https://newtonrouter.com，避免请求路径出现 /v1/v1。

Chat Completions 调用示例

将 YOUR_API_KEY 换成自己的密钥，MODEL_ID 换成支持 Chat Completions 接口的可用模型 ID。 

curl https://newtonrouter.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

价格和可用模型以哪里为准？

模型定价页面展示当前可用模型及其价格。输入和输出 Token 的单价可能不同，所选分组也会影响费用；调用前请查看模型的计费单位和规则。

折扣套餐页面展示可购买的订阅套餐和 Token 用量估算。估算受所选模型及输入、输出比例影响，不是保证可使用的 Token 配额。可用模型、价格和套餐可能调整。

常见问答

NewtonRouter 是模型厂商的官网吗？

NewtonRouter 是将请求转发到上游服务的 API 平台。OpenAI/GPT、Anthropic/Claude 和 xAI/Grok 是独立的厂商和品牌，其名称仅用于标识模型系列，不代表官方背书。

一个接口能使用所有厂商的全部功能吗？

支持范围取决于模型、接口和渠道。兼容 OpenAI API 不意味着支持全部厂商专有功能；请查看模型支持的接口，并测试应用需要的功能。

24h 成功率代表什么？

它是模型定价页面展示的服务历史统计，不是未来可用性保证，也不是厂商官方状态。如果分组使用某个模型作为数据来源，页面标出的模型名称即为该统计对应的模型。

在哪里查看消费？

登录后可在控制台查看余额、调用日志和用量记录。

如何联系支持？

可通过 newtonrouter@gmail.com 联系支持。服务条款和数据处理说明请查看用户协议和隐私政策。
